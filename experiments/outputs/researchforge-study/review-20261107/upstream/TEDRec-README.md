# TEDRec: Transformer-based Scientific Collaborator Recommendation via Textual-Edge Dynamic Network Modeling

[![DOI](https://img.shields.io/badge/DOI-10.1016/j.ipm.2025.104283-blue)](https://doi.org/10.1016/j.ipm.2025.104283)

## Introduction

This repository contains the Python implementation of all models described in our paper:
> **TEDRec: Transformer-based Scientific Collaborator Recommendation via Textual-Edge Dynamic Network Modeling**,
> *Information Processing & Management*, 2025. DOI: [10.1016/j.ipm.2025.104283](https://doi.org/10.1016/j.ipm.2025.104283)

The project provides the full training pipeline for the TEDRec model, including pre-trained model parameters so that readers can reproduce experimental results without retraining from scratch.

## Requirement

- Python 3.10.14

Dependencies are listed in `requirement.txt`. Install them with:

```shell
pip install -r requirement.txt
```

## Data

We use the **DBLP citation network V14** (updated at 2023-01-31) as the experimental dataset, filtered by CCF-A venues. The original data is available from [AMiner](https://www.aminer.cn/citation). Preprocessed data can be downloaded from [Google Drive](https://drive.google.com/file/d/1jDUnRCFY1uazBz2YInYWbId1fbXoV5KY/view?usp=drive_link).

After downloading and unzipping, place the files under `./data/` as follows:

```
./data/
├── Dataset/                          # CCF-A journal and conference reference lists
│   ├── CCF-A.csv
│   ├── CCFUrl.txt
│   ├── CCF_AI_A/                    # CCF-A AI field venue files
│   ├── CCF_DM_A/                    # CCF-A DM field venue files
│   └── *.json
├── dblp_v14_process/                # Processed DBLP data (downloaded from Google Drive)
│   ├── ccfa_ai_data.csv
│   ├── ccfa_dm_data.csv
│   ├── dict_ccf_map.json
│   └── dict_id_author_all.json
├── node_process_ai/                 # (generated by Step 1)
├── node_process_dm/                 # (generated by Step 1)
├── pretrain/pretrain_ai/            # (generated by Step 1)
└── pretrain/pretrain_dm/            # (generated by Step 1)
```

- Files under `dblp_v14_process/` are **external inputs** downloaded from the Google Drive link above.
- Files under `node_process_*/`, `pretrain/pretrain_*/`, and `dblp_v14_process/*.csv` are **generated by the pipeline** (Step 1) and should not be committed to the repository.

## Code

The pipeline consists of 6 sequential stages:

| Stage | File | Description |
|-------|------|-------------|
| 1 | `1. construct_graph.py` | Build collaboration graphs, train Node2Vec embeddings, generate train/val/test splits |
| 2 | `data/pretrain/main.py` | Pretrain BERTMF model for textless author embeddings |
| 3 | `2.0 Edge-embedding.py` | Train Heterformer / MeanSAGE / MaxSAGE for author representation learning |
| 4 | `3. csv2resources.py` | Convert graph edges to serialized sequential recommendation format |
| 5 | `4.train_model.py` | Train GPT2-based sequential recommendation model |
| 6 | `5. eval_single_step.py` | Evaluate model performance |

Implementation details for Stages 3 and 5 can be found in `utils/run/` and `utils/models/` respectively.

## Usage

### Step 1: Construct graph data

```shell
python 1. construct_graph.py
```
This generates collaboration edge lists (`ml_ai_direct_aminer.csv`, etc.), author index mappings (`.pkl`), Node2Vec models, and train/val/test split files (`.tsv`).

### Step 2: Pretrain textless node embeddings

```shell
cd data/pretrain/
bash run.sh
```

Then run the cells in `data/pretrain/transfer_embed.ipynb` to transfer BERTMF embeddings to the training directories.

### Step 3: Model training and inference (author representation learning)

```shell
cd ../..
# Training
python 2.0\ Edge-embedding.py --data_path data/node_process_ai --pretrain_embed True --model_type Heterformer --data_mode text --epochs 16 --pretrain_dir data/node_process_ai/pretrain_ai --load True
# Inference
bash 2.\ edge-embdding.sh
```

For detailed parameter options, see the preamble of `2.0 Edge-embedding.py`.

### Step 4: Convert to sequential recommendation format

```shell
python 3. csv2resources.py
```

### Step 5: Train and test GPT2 sequential recommendation model

```shell
# Train
bash 4.0\ train_seed_aminer.sh
# Infer
bash 4.1.\ test_seed_aminer.sh
```

For detailed parameter options, see `utils/gpt2_args_parser.py`.

### Step 6: Evaluate

```shell
python 5. eval_single_step.py
```
